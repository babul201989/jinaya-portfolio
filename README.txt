JINAYA'S LITTLE WORLD — MULTI-PAGE WEBSITE

1. Extract this ZIP file.
2. Open the Jinaya-Portfolio folder.
3. Put your photos in the images folder and name them:
   cover.jpg, baby1.jpg, baby2.jpg ... baby8.jpg
4. Put your videos in the videos folder and name them:
   video1.mp4, video2.mp4, video3.mp4, video4.mp4
5. Double-click index.html to open the website in your browser.
6. To edit text, right-click an HTML file and choose Edit with Notepad++.
7. Keep all seven HTML files and style.css in the same main folder.
8. Do not rename the folders unless you also update the image/video paths in the HTML.

PAGES
- index.html       Home
- about.html       My Story
- milestones.html  My Milestones
- gallery.html     Photo Gallery
- videos.html      Video Memories
- adventures.html  Family Adventures
- daddy.html       Letter from Daddy
- style.css        Shared design and styling

The site uses Google Fonts when internet access is available. It still works without them, using fallback fonts.
